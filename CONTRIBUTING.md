## Contributing

Thanks for helping improve UI Agent.

### How to contribute

- Open an issue before starting larger features or behavior changes.
- Keep pull requests focused on one problem at a time.
- Include reproduction steps for bug fixes and a short demo for CLI or automation changes.

### Local setup

```bash
pip install -r requirements.txt
pip install .
```

### Validation

- Run the relevant CLI command you changed.
- Verify the documented flow in `README.md` still matches behavior.
- Mention platform-specific limitations in the PR description when relevant.

### Pull request checklist

- Describe what changed and why.
- Link the related issue.
- Avoid unrelated refactors in the same PR.
